# Beautiful Clock: The Hour That Happens Twice

A beautiful Eastern Time clock built to record the daylight saving fall-back transition, the moment 2:00 AM EDT becomes 1:00 AM EST and the 1 AM hour happens twice.

## What it does

- Live analog dial and digital readout for America/New_York, with a live EDT/EST indicator
- Real-time countdown to the fall-back jump
- A Transition Recorder that detects the actual UTC-4 to UTC-5 flip the second it happens and stamps it into a log you can download
- A Replay button that re-runs the seconds around the jump at any time
- Short explainers on why 1:30 AM happens twice and when spring forward falls

## Run it

Open `index.html` in any browser. No build step, no dependencies apart from Google Fonts.

Live: https://gagan-git-sardar.github.io/beautiful-clock/
